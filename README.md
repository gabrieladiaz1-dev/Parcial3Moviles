# Parcial3Moviles

Sistema Integral de Gestión Hospitalaria — Hospital Universitario (UNICAES, 2026).

| Carpeta | Sistema |
|---|---|
| `AdminHospital/` | Plataforma web administrativa (React, TypeScript, Vite) |
| `Hospital-Universitario/` | Aplicación iOS (SwiftUI) y su vista previa web |
| `Android/` | Aplicación Android de recepción (Kotlin) |

Cada carpeta conserva su propio README con las instrucciones de configuración. Los archivos de configuración local con claves (`.env`, `supabase.properties`) no se incluyen; usa los archivos `*.example` como plantilla.
